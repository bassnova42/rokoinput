# 洛克输入法 · Roko Input

**简体中文** · [English](README.en.md)

仅供非商业个人使用的 macOS 语音输入项目。按住自定义快捷键说话，松开结束，将最终文字输入到光标处。

## 只用苹果模型，强制本地识别

只使用苹果系统内置的 **Speech 框架和端侧语音模型**，不包含第三方识别模型、云端ASR接口、API Key、分析SDK或应用联网客户端。

每次请求强制设置 `requiresOnDeviceRecognition = true`，开始前检查 `supportsOnDeviceRecognition`。设备不支持中文端侧识别，或本地资源不可用时，提示错误并停止，**不回退云端识别**。语音识别在本机完成，不上传音频或转写文字。

这指应用的语音识别策略，并不代表整个 macOS 没有任何网络连接。模型资源由苹果管理，系统准备或下载缺失的语言资源可能需要联网；资源就绪后才具备离线使用条件。设备、系统与语言会影响支持情况和准确率。参考苹果的[端侧识别要求](https://developer.apple.com/documentation/speech/sfspeechrecognitionrequest/requiresondevicerecognition)和[支持能力检查](https://developer.apple.com/documentation/speech/sfspeechrecognizer/supportsondevicerecognition)。

**0.4.0 已改变旧原型的行为**：旧版本允许苹果决定处理地点，新版本才强制端侧识别。旧版试用结果不能证明新版的准确率或离线可靠性。

## 功能

- 默认只在菜单栏运行，不自动打开主窗口；设置和统计从Roko菜单打开。
- 默认按住 F5 说话，松开立即停止采音；按住不足0.5秒会提醒时间太短，并取消本次输入，不写文字日志、不累计统计。
- 录音时屏幕底部显示橙色渐变波形小胶囊，柱高反映麦克风真实音量；松开显示识别中，成功后隐藏。悬浮条不抢占编辑器焦点，波形不代表识别进度。
- 用户可录制功能键，或包含 Command/Option/Control 的组合键；设置会保存，注册冲突时保留原设置。
- 苹果自动标点、临时文字显示与最终结果编辑。
- InputMethodKit 系统输入法集成；自动输入只走系统输入法接口，不申请或依赖辅助功能权限。
- 统计窗口：今日识别字数、成功次数、录音分钟数、平均首字耗时、最近七天逐日数据、累计字数。
- 可关闭的本机文字日志与菜单栏常驻。

不包含拼音候选词引擎，普通键盘输入透传，不会自动按回车、发送消息或提交表单。

## 要求与源码构建

macOS 13+、Apple Silicon 或 Intel、Xcode Command Line Tools、麦克风和可用的苹果中文（`zh-CN`）端侧语音资源。需要麦克风和语音识别权限；无需辅助功能权限，跨应用输入前请先选中洛克输入法。

**项目仅保留源代码，没有DMG/PKG安装包、预编译App、发布压缩包或安装包生成脚本。** 本地构建：

```sh
zsh scripts/test.sh
zsh scripts/build.sh
```

构建脚本使用系统框架生成本机的通用应用 `build/Roko Input.app`，采用ad-hoc签名；产物已被Git忽略，不随源码分发。没有第三方包依赖。

需要本机安装时，先退出运行中的洛克输入法，再执行：

```sh
zsh scripts/install-local.sh
```

这是**源码脚本**，不是安装文件。它会本地构建，将App复制到 `~/Library/Input Methods/Roko Input.app`，把旧版本备份到应用数据目录，注册并启用输入源，不自动切换当前输入法。在系统设置 → 键盘 → 文本输入 → 编辑 → + 中添加洛克输入法；未刷新时请注销并重新登录。本地构建未使用Developer ID签名或公证。

## 使用与快捷键设置

1. 选择系统输入法菜单中的洛克输入法；未选中时仅提示切换，不要求辅助功能授权。
2. 将光标放到普通输入框，按住 F5，录音开始后说话，松开结束。
3. 等待最终结果后自动输入。若检测到目标App/输入框改变，保留文字供手动复制。
4. 从Roko菜单打开设置，点击「设置快捷键」，直接按下新组合键。Esc取消，「恢复F5」恢复默认。不支持只有修饰键的绑定。
5. 点击「查看输入统计」，或在菜单栏选择「输入统计」。

部分键盘需要按住Fn+F5。与系统听写或其他软件冲突时，请自行调整相关设置，程序不擅自修改系统快捷键。窗口里的开始/结束按钮用于手动测试，结果不自动写入其他App。关闭窗口后仍在菜单栏运行。

系统安全输入模式会阻止听写；不要在普通文本框中听写秘密。自动提交只通过InputMethodKit，不模拟按键、不使用剪贴板粘贴；手动点击复制按钮时仍会写入剪贴板。

## 授权流程与分句

麦克风和语音识别已授权时直接录音，仅在对应状态为尚未决定时请求权限。首次授权与听写分开，完成后提示重新按住快捷键，不把授权期间的松键当作识别失败。拒绝或受限制时给出说明，不重复弹框。开发版本重新签名后，macOS仍可能要求重新授权；程序无法替代系统的身份判断。

当识别结果有可靠、互不重叠的音频时间戳时保留前面的句子；重叠结果作为同句修正。没有时间信息时不盲目拼接。该处理减少客户端覆盖问题，不能恢复苹果没有识别出来的语音，也不保证长段完整性。系统诊断日志只记录字数、时间信息是否可用等元数据，不记录转写正文。

## 错误排查

`kLSRErrorDomain / 201` 表示系统Siri和听写均被关闭。请在 **系统设置 → 键盘 → 听写** 中开启，亲自审阅苹果的系统隐私提示，再重试。这是系统服务的前提条件，与洛克强制端侧识别的策略分开；程序不会自行打开系统听写。102表示本地语音资源缺失，1110表示未识别到语音。

## 统计口径

仅统计功能上线后完成的、非空的**最终识别结果**，每次听写记一次，包括手动测试。它衡量识别量，不等同于目标编辑器已经成功收到文字。失败/中断的临时结果不计；事后编辑、复制不会重复计数。当前单次录音上限55秒，到达时会明确提示松开后重新按住；超过上限继续说的话不会被采集。

按包含字母或十进制数字的Swift字符簇计数。中文字符、英文字母和数字逐个计数；不计标点、空白或表情。不是英文单词数。日期使用系统本地日历和时区；录音时间不含等待最终结果；首字时间从创建识别请求开始，不是从实际开口时开始。

统计文件：

```text
~/Library/Application Support/Roko Input/statistics.json
```

只保存日期和数值汇总，**不保存转写内容**。关闭文字日志后统计仍生效，不会偷偷导入旧日志。统计文件损坏时提示错误而不覆盖。退出App后删除该文件可清空统计。

## 文字日志与隐私

```text
~/Library/Application Support/Roko Input/History/YYYY-MM-DD.jsonl
```

按此前要求默认开启，每次非空语音输入一条记录，一次说多句也保存在一条中；不重复记录中间结果。中断文字会标记 `final: false`；新增日志标明苹果端侧识别。**不保存原始录音。**

点击「打开文字日志目录」即可查看；取消「保存每次转写的文字历史」停止新增文字记录，不会删除已有内容或关闭数值统计。可在Finder删除指定日期日志。

日志为明文、不自动过期，系统备份或同账号其他程序仍可能读取。History目录权限0700，文字文件和统计文件权限0600。日志与统计不进入Git，也不由本项目上传。不要把私人日志提交到公开issue。

## 源码与验证范围

`Sources/` 包含端侧识别、快捷键、文字提交、历史和统计；`Resources/` 为输入源元信息及本地化；`Tests/` 检查按住/松开状态、日志编码与权限、统计计数/聚合/损坏处理和快捷键序列化；`scripts/` 仅包含源码构建、本机安装、测试及图标生成。

自动测试和编译通过不等于真实麦克风识别、全局按键、网络流量与所有编辑器都已验证。请在获得权限后自行测试，也应在网络不可用时验证。设备不支持端侧模型时，应用会停止识别，不提供云端回退。

### 设置页面

通过系统输入法菜单中的 **洛克输入法设置…** 打开四个页面：

- **语音输入**：三步教程、橙色 F5 键盘示意、麦克风及语音识别权限状态，以及手动试说预览。修改说话键后，教程会显示当前快捷键。
- **快捷键**：分别录制“按住说话”和“切换到洛克输入法”的全局快捷键。切换键可不设置，仅切换输入法、不开始录音；重复或被占用时保留原设置。需先在系统中添加洛克输入法。
- **输入统计**：今日字数、次数、说话时长、平均首字耗时、累计字数与七日趋势。计数表示识别结果，不代表成功写入其他应用。
- **输入日志**：开关文字记录、按日期浏览、搜索当天内容、复制记录，或在 Finder 打开日志目录。关闭记录不会删除已有内容。不保存录音。

键盘图形随源码及本机编译的应用一起提供，设置页面无需联网。
